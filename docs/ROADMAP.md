### 0. 리액트로 옮기기 (정식 앱 출시 준비) — **진행 중, 이 일이 먼저**
정식 앱(앱스토어·플레이스토어) 출시를 위해 React + TypeScript로 옮기고, 그다음 Capacitor로 앱 포장을 해요.
리액트 네이티브는 쓰지 않아요(웹 버전과 공유 링크가 필요하고, 지금 디자인 CSS를 그대로 살리기 위해).
옮기는 동안 새 기능은 멈춰요. 새 기능은 옮긴 뒤 다른 대화에서 해요.

- [x] **1단계 · 뼈대**: Vite + React + TypeScript. 예전 코드(`src/`)와 리액트(`app/`)가 한 페이지에서 같이 돌아가요.
  빌드 결과는 지금처럼 저장소 맨 위(`index.html` + `assets/`)라서 배포 방식은 그대로예요.
  첫 화면으로 **사용 안내**를 옮겼어요(`app/screens/HelpPanel.tsx`). 점검 80개 통과.
- [ ] **2단계 · 데이터 부분**: 저장(localStorage)·여행 데이터 모양(타입)·동기화(`310-sync.js`)·서버 연결을 `app/data/`로 옮겨요.
  예전 코드가 여러 파일에서 같은 변수(`placed`, `profile`, `SYNC` 등)를 직접 고치고 있어서, 한 덩어리씩 "가져오기/저장하기" 함수로 바꿔 가며 옮겨요.
- [ ] **3단계 · 화면 옮기기**: 작은 화면부터. 설정 → 더보기 메뉴 → 내 여행 목록 → 친구와 함께 → 알림 → 찾기 → 일정표(가장 큰 것, 마지막).
  화면마다 id·class 이름을 그대로 두고 자동 점검이 계속 통과하는지 확인해요.
- [ ] **4단계 · 앱 포장**: Capacitor(아이폰·안드로이드), 폰 자체 알림(Firebase), 앱 안 계정 삭제, 개인정보처리방침, 안드로이드 빌드 자동화.
  사용자 준비물: 애플 개발자($99/년), 구글 플레이($25, 비공개 테스트 12명·14일), Firebase 프로젝트, 아이폰 빌드용 맥 또는 클라우드 빌드.
- 정해야 할 것(4단계 전까지): AI 키를 운영자가 낼지(서버에서 사용량 제한) / 지금처럼 이용자가 넣을지. Supabase 유료(월 $25) 전환. 위치정보법 신고 필요 여부 확인.

### 1. 계획(J) / 즉흥(P) 모드 차이를 극적으로 — **사용자 결정 대기 · 리액트로 옮긴 뒤에**
새 디자인에서 테마 색이 헤더를 차지해 P 모드의 분홍 포인트가 거의 안 보여요. 제안한 5가지:
1. 바탕 질감: J는 옅은 모눈, P는 점선 노트/빈 종이
2. 일정 카드: J는 시간 눈금 블록(정확한 시간), P는 살짝 기운 포스트잇("2시쯤", 구간 제목 손글씨, 빈 시간에 큰 "🎲 굴려 보기")
3. 헤더: P에서 날짜 제목 살짝 기울기 + "오늘은 즉흥!" 손글씨 스티커, 헤더 그림을 주사위·낙서로
4. 전환 애니메이션: J→P 주사위가 굴러가며 블록이 포스트잇으로 흩어짐, P→J 착착 정렬 (움직임 줄이기 설정 존중)
5. 모드 버튼을 "📐 계획 | 🎲 즉흥" 큰 스위치로
- 추천: 2 + 4가 가장 효과 큼. 사용자가 "바로 앱에" 또는 "시안 먼저" 중 고르기로 함.
- 관련 코드: P 화면 `170-quick-start-pview.js`(renderPView, 시간 구간 BUCKETS), 모드 색 `01-base-layout.css`의 `body.mode-p`, 헤더 `389a-look.js`·`17-look.css`.

## 정해 둔 결정
- 정식 앱: React + TypeScript + Vite, 앱 포장은 Capacitor. 리액트 네이티브는 안 씀. 예전 코드와 함께 돌리며 화면 단위로 옮김.
- 빌드 결과는 저장소 맨 위(`index.html`, `assets/`) → GitHub Pages 설정은 그대로.
- 디자인: 3번(컬러 블록) 구조 + 1번(엽서)의 제목 강조. 헤더는 스크롤하면 한 줄로 접힘. 탭은 아래 고정. 내 여행 목록은 엽서 카드.
- 스타일은 겉모습만 바꾸고 배치는 같게(기능 수정이 스타일마다 갈라지지 않게).
- 손글씨 메모는 모든 스타일에 기본.
- 장소 찾기는 "찾기 화면 하나, 입구 여러 개". 결과는 항상 [일정에 넣기 / 장소에만 / 안 함].
- 같은 장소는 자동으로 묶지 않음(항상 사용자가 확인).
- 여행자 추천(👍)은 익명 집계, 보기는 누구나, 추천은 로그인 필요.
- 데모는 저장·동기화되지 않는 칸막이 안에서만 열림.
- 로그인: 이메일+비밀번호. 서버 주소·공개 키는 앱에 내장.
