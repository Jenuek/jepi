### 0-1. 실제 서버에서 찾은 문제
- **AI가 가끔 "찾지 못했어요"·"답하지 않았어요"** (다시 누르면 됨, 3단계 배포 Jenuek/jepi#6 뒤 사용자 제보). 원인 후보 셋을 모두 고침:
  ① AI 서버가 잠깐 바쁠 때(529·5xx)나 연결이 끊길 때 한 번에 실패 처리 → 이제 잠깐 기다렸다 최대 3번, 그래도 안 되면 다른 AI(둘 다 연결 시).
  ② 장소 24곳처럼 긴 답은 8000토큰에서 잘려 JSON이 깨질 수 있었음 → 16000으로, 잘리면 "too_long"으로 알려 줌. 깨진 답은 한 번 다시 물어요.
  ③ 긴 답은 100초를 넘길 수 있었음 → 무거운 일 180초, 가벼운 일 90초.
  안내 글도 이유별로(바빠요·너무 오래 걸렸어요·잘렸어요·답을 읽지 못했어요). 점검 추가(바쁨 2번 뒤 성공, 깨진 답 재요청, 틀린 키는 바로 멈춤). 점검 284개 통과.
  실제 원인 중 어느 것인지는 사용자 기기에서 다음 오류 문구로 확인.
- **친구와 함께가 실제 서버에서 동작한 적이 없었음**(가짜 서버 점검에선 통과): 여행을 만든 뒤 나를 멤버로 넣는 규칙이 "내가 만든 여행인지" 보려고
  여행을 들여다보는데, 아직 멤버가 아니라 안 보여서 거절됨 → 다시 누르면 `duplicate key … jepi_trips_pkey`.
  1차: trips_sel에 `owner=auth.uid() or …` 추가 + 앱 ignore-duplicates → 실제 서버에서 여전히 `new row violates row-level security policy`.
  2차(지금): 공유를 서버 함수 `jepi_share`(security definer, jepi_join처럼) 하나로 — 여행 만들기/반쯤 된 내 여행 되찾기 + 나를 owner 멤버로를 한 번에.
  **사용자가 schema.sql의 jepi_share 부분을 SQL Editor에서 실행해야 함.**
  가짜 서버도 실제처럼(같은 여행 두 번 넣기 409, 멤버 넣기는 내가 만든 여행만). 점검 187개.
- 카카오 "요청을 막았어요": 앱이 공개되지 않은 경로 주소(`dapi.kakao.com/v2/routing/…`)를 부르고 있었음. 사용자 결정으로
  **국내는 거리로 어림(≈) + "안내 시작"은 카카오맵(출발→도착)으로**. 카카오 키는 장소·주소 검색용(내 장소·🎲), "확인"도 장소 검색으로 해요.
  서버 규칙(trips_sel)은 사용자가 SQL Editor에서 실행함.

### 1. 계획(J) / 즉흥(P) 모드 차이를 극적으로 — **사용자 결정 대기 · 리액트로 옮긴 뒤에**
새 디자인에서 테마 색이 헤더를 차지해 P 모드의 분홍 포인트가 거의 안 보여요. 제안한 5가지:
1. 바탕 질감: J는 옅은 모눈, P는 점선 노트/빈 종이
2. 일정 카드: J는 시간 눈금 블록(정확한 시간), P는 살짝 기운 포스트잇("2시쯤", 구간 제목 손글씨, 빈 시간에 큰 "🎲 굴려 보기")
3. 헤더: P에서 날짜 제목 살짝 기울기 + "오늘은 즉흥!" 손글씨 스티커, 헤더 그림을 주사위·낙서로
4. 전환 애니메이션: J→P 주사위가 굴러가며 블록이 포스트잇으로 흩어짐, P→J 착착 정렬 (움직임 줄이기 설정 존중)
5. 모드 버튼을 "📐 계획 | 🎲 즉흥" 큰 스위치로
- 추천: 2 + 4가 가장 효과 큼. 사용자가 "바로 앱에" 또는 "시안 먼저" 중 고르기로 함.
- 관련 코드: P 화면 `170-quick-start-pview.js`(renderPView, 시간 구간 BUCKETS), 모드 색 `01-base-layout.css`의 `body.mode-p`, 헤더 `389a-look.js`·`17-look.css`.

## 정해 둔 결정
- 정식 앱: React + TypeScript + Vite, 앱 포장은 Capacitor. 리액트 네이티브는 안 씀. 예전 코드와 함께 돌리며 화면 단위로 옮김.
- 빌드 결과는 저장소 맨 위(`index.html`, `assets/`) → GitHub Pages 설정은 그대로.
- 디자인: 3번(컬러 블록) 구조 + 1번(엽서)의 제목 강조. 헤더는 스크롤하면 한 줄로 접힘. 탭은 아래 고정. 내 여행 목록은 엽서 카드.
- 스타일은 겉모습만 바꾸고 배치는 같게(기능 수정이 스타일마다 갈라지지 않게).
- 손글씨 메모는 모든 스타일에 기본.
- 장소 찾기는 "찾기 화면 하나, 입구 여러 개". 결과는 항상 [일정에 넣기 / 장소에만 / 안 함].
- 같은 장소는 자동으로 묶지 않음(항상 사용자가 확인).
- 여행자 추천(👍)은 익명 집계, 보기는 누구나, 추천은 로그인 필요.
- 데모는 저장·동기화되지 않는 칸막이 안에서만 열림.
- 로그인: 이메일+비밀번호. 서버 주소·공개 키는 앱에 내장.
