- 진단: 지금 P는 J 시간표를 오전·오후로 묶어 다시 보여 주는 것. 위쪽(D-day·예산·이동 줄)도 J와 같음. 🎲 후보 카드가 시간 순서와 다르게 아래에 붙음.
- 컨셉: **J는 미리 정하는 앱, P는 그때그때 고르는 앱.** P는 "지금"부터 보여 줌.
- 정해진 것(사용자):
  - P 디자인은 **보드게임풍**: 하루 = 칸을 따라가는 판(출발 숙소 → 지나온 칸 ✓ 도장 → 지금 칸에 말 → 빈 시간은 ? 칸 → 예약은 깃발 칸 → 도착 숙소),
    🎲 굴리기 = 카드 뽑기(이 카드로 갈래요 / 다시 뽑기 / 모아 두기), 가고 싶은 곳 = 손에 든 카드, 기분 = 동그란 칩.
    두꺼운 테두리·번지지 않는 그림자·원색, 가운데 영역 제목·버튼만 둥근 글씨(주아체), 설명 글은 지금 고딕 그대로.
  - **머리글과 아래 탭은 J와 똑같이**(테마색·명조 여행 제목·모드 버튼·일정/장소/지도/더보기). 바뀌는 건 가운데만. 모드 표시는 모드 버튼과 탭 글자 색(P 분홍)뿐.
  - 판은 **한 장에 4칸×3줄 지그재그(10칸)**. 칸이 넘치면 **판을 옆으로 넘겨 다음 장**(점·"1 / 2장" 표시, ‹ › 버튼도). 한 줄로 길게 미는 방식은 사용자가 뺌.
  - **판은 그날 아침에 열리는 게 기본**, 원하면 "미리 열어서 계획하기"를 켜서 카드를 ? 칸에 미리 놓을 수 있음(안 놓은 칸은 그날 굴림). 꼭 지킬 시간(비행기·숙소·예약)은 열리기 전에도 깃발로 보임.
  - 출발 전 P는 일정표 대신 "출발까지 N일 · 판은 그날 아침에" + 모아 둔 카드 + 준비물 3개만(전체 목록은 J에서).
  - 모드 버튼 이름은 **"J모드 / P모드"**(계획·즉흥 아님). 가고 싶은 곳 카드 묶음은 **"내 카드"**("손패" 안 씀).
  - 끝난 칸에는 **도장처럼 뚜렷한 완료 표시**(분홍 이중 원 "다녀옴", 기울어진 고무도장, 출발 칸은 "출발!").
  - 기분 고르기 + 굴리기는 **한 주사위 판(초록 트레이) 안에** "① 어떤 주사위를 굴릴까요? ② 굴려요"로 묶음. 기분마다 색이 다른 주사위,
    고른 주사위가 들리고 버튼의 주사위 색·글자("배고파 주사위 굴리기!")가 따라감.
  - **주사위 6개**(사용자 결정): 아무거나 · 배고파 · 차분히 · 도파민 · 내 카드 · 다리 아파. "비 와요"·"한잔"은 빼고 자동으로 챙김.
    | 주사위 | 나오는 곳 | 바탕(지금 코드) |
    |---|---|---|
    | 아무거나 | 전부. ♥·취향 키워드·시즌·추천 많은 곳·가까운 곳이 더 잘 나옴 | `diceCands` 가중치 그대로 |
    | 배고파 | 식사(food). 최근 5일 안에 간 식당은 빼고, 점심·저녁 때에 맞춤 | `dice.lunch`·`recent` |
    | 차분히 | 전시·산책(art·walk) + 카페·정원·서점·공원 | 예전 `quiet` |
    | 도파민 | 쇼핑·공연·체험·놀이·전망(shop·music + 액티비티·체험 태그), 저녁 이후엔 night도 | 예전 `move`에서 산책 뺌 |
    | 내 카드 | ♥ 해 둔 곳만. 없으면 "내 카드가 비어 있어요 — 장소 탭에서 ♥ 해 봐요" | `isWish` |
    | 다리 아파 | 걸어서 10분 안만, 카페·공원·짧게 머무는 곳이 더 잘 나옴 | `dice.walk` 걷기 제한 |
    - 자동: 저녁 이후엔 모든 주사위에서 술집·야경(night)이 더 잘 나옴(지금 P 일정 규칙). 날씨 기능이 생기면 비 오는 날 실내(art·shop·music·food)가 더 잘 나옴.
  - 주사위마다 **눈 1~6**(아무거나 1 · 배고파 2 · 차분히 3 · 도파민 4 · 내 카드 5 · 다리 아파 6), 색도 주사위마다 다름. 굴리기 버튼 안 주사위도 고른 눈을 보여 줌.
  - 장소 카드는 **실제 카드 비율 5:7**(뽑은 카드 270×378, 뒤에 남은 카드 더미). 카테고리마다 **색 + 픽토그램**
    (식사·카페 포크·나이프, 음악 음표, 미술 액자, 산책 나무, 쇼핑 가방, 밤·바 달, 이동·짐 가방) — 견본은 캔버스의 "카테고리 카드 · 픽토그램".
- 제안(사용자 검토 중): **꾸미기 스타일마다 J·P 한 쌍**. 스타일은 겉모습만, 배치(판 4×3·주사위 판·카드)는 모두 같게. 머리글·탭은 같은 스타일 안에서 J·P 같음.
  - 컬러 블록: J = 지금 시간표, P = 보드게임판(2차 시안)
  - 여행 수첩(`style-note`): J = 줄 노트 수첩, P = **흑백 스케치북**(연필 선·손그림 칸과 주사위, 색은 빨간 인주 도장과 지금 칸 정도만. ? 칸·고른 주사위는 색 대신 빗금·굵은 선으로 구분)
  - 코드: 이미 `body.style-note`와 `body.mode-p`가 따로 있어 `body.style-note.mode-p`로 조합 가능.
- 아직 정할 것: 스타일별 J·P 한 쌍 제안 확정 여부, 모드 전환 움직임(주사위가 구르며 판이 펼쳐짐),
  지금 화면의 "남은 시간" 문구, 언제 앱에 넣을지(지금 / 앱 포장 뒤).
- 예전 제안(참고):
새 디자인에서 테마 색이 헤더를 차지해 P 모드의 분홍 포인트가 거의 안 보여요. 제안한 5가지:
1. 바탕 질감: J는 옅은 모눈, P는 점선 노트/빈 종이
2. 일정 카드: J는 시간 눈금 블록(정확한 시간), P는 살짝 기운 포스트잇("2시쯤", 구간 제목 손글씨, 빈 시간에 큰 "🎲 굴려 보기")
3. 헤더: P에서 날짜 제목 살짝 기울기 + "오늘은 즉흥!" 손글씨 스티커, 헤더 그림을 주사위·낙서로
4. 전환 애니메이션: J→P 주사위가 굴러가며 블록이 포스트잇으로 흩어짐, P→J 착착 정렬 (움직임 줄이기 설정 존중)
5. 모드 버튼을 "📐 계획 | 🎲 즉흥" 큰 스위치로
- 추천: 2 + 4가 가장 효과 큼. 사용자가 "바로 앱에" 또는 "시안 먼저" 중 고르기로 함.
- 관련 코드: P 화면 `170-quick-start-pview.js`(renderPView, 시간 구간 BUCKETS), 모드 색 `01-base-layout.css`의 `body.mode-p`, 헤더 `389a-look.js`·`17-look.css`.

## 정해 둔 결정
- 정식 앱: React + TypeScript + Vite, 앱 포장은 Capacitor. 리액트 네이티브는 안 씀. 예전 코드와 함께 돌리며 화면 단위로 옮김.
- 빌드 결과는 저장소 맨 위(`index.html`, `assets/`) → GitHub Pages 설정은 그대로.
- 디자인: 3번(컬러 블록) 구조 + 1번(엽서)의 제목 강조. 헤더는 스크롤하면 한 줄로 접힘. 탭은 아래 고정. 내 여행 목록은 엽서 카드.
- 스타일은 겉모습만 바꾸고 배치는 같게(기능 수정이 스타일마다 갈라지지 않게).
- 손글씨 메모는 모든 스타일에 기본.
- 장소 찾기는 "찾기 화면 하나, 입구 여러 개". 결과는 항상 [일정에 넣기 / 장소에만 / 안 함].
- 같은 장소는 자동으로 묶지 않음(항상 사용자가 확인).
- 여행자 추천(👍)은 익명 집계, 보기는 누구나, 추천은 로그인 필요.
- 데모는 저장·동기화되지 않는 칸막이 안에서만 열림.
- 로그인: 이메일+비밀번호. 서버 주소·공개 키는 앱에 내장.
